# 🌐 Personal Portfolio Website

## 📌 Project Overview

Welcome to my Personal Portfolio Website! This project is a simple and beginner-friendly website developed using HTML and CSS. The main goal of this project is to practice my front-end web development skills and understand how to create, design, and organize web pages.

The website includes two main pages: a Home page and a Contact page. 

This project represents my first steps toward building websites and improving my knowledge of web development.

## 🎯 Objectives

- Learn the fundamentals of HTML and CSS.
- Understand the structure of a website.
- Practice creating and styling web pages.
- Learn how to link multiple pages together.
- Improve my understanding of layouts, colors, fonts, spacing, and basic design.
- Gain practical experience by building a real website project.
- Learn how to manage and showcase projects using GitHub.

## 📄 Pages Included

### 🏠 1. Home Page

The Home page is the main page of my portfolio website. It introduces the purpose of the website and acts as the starting point for visitors.

**Highlights:**
- Simple and clean page layout.
- Basic styling using CSS.
- Easy navigation to other pages.
- A beginner-friendly design focused on simplicity and readability.

### 📩 2. Contact Page

The Contact page is designed to help visitors find contact information and connect with me.

**Highlights:**
- Simple and organized layout.
- Basic CSS styling for a consistent appearance.
- Easy navigation back to the Home page.
- A dedicated page for contact-related information.

## 🛠️ Technologies Used

### HTML5
HTML is used to create the structure and content of the website, including headings, paragraphs, links, and page sections.

### CSS3
CSS is used to style the website by controlling colors, fonts, spacing, alignment, and the overall appearance of the pages.

## ✨ Key Features

- Two separate web pages: Home and Contact.
- Simple and user-friendly structure.
- Basic CSS styling.
- Navigation between pages.
- Organized HTML and CSS code.
- Beginner-friendly project structure.
- No complex frameworks or libraries required.

## 🚀 How to Run the Project

1. Clone or download this repository from GitHub.
2. Extract the downloaded files if necessary.
3. Open the project folder on your computer.
4. Locate the `index.html` file.
5. Open it in your preferred web browser.
6. Navigate between the Home and Contact pages to explore the website.
